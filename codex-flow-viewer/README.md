# Codex Flow Viewer

설치·실행·MCP 연결은 [저장소 안내](../README.md)와 [다른 컴퓨터 사용 매뉴얼](docs/other-computer-manual.ko.md)을 확인하세요.

이 폴더에서 `npm.cmd ci`, `npm.cmd run build`, `start-viewer.cmd` 순서로 실행합니다. Node.js 24.18 이상이 필요합니다.

`server/chatgpt`, `src/ChatGptImports.tsx`와 관련 테스트·패키징 스크립트는 이전 사본 기능의 호환/검증 코드입니다. 현재 프로덕션은 사본 가져오기 UI/API를 활성화하지 않습니다.
